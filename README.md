# بيك أب وعائلي في السعودية حتى 120 ألف ريال

صفحة فيها إعلانات البيك أب والسيارات العائلية حتى 120 ألف ريال من كل مدن المملكة، بدون الماركات الصينية.
المصادر: حراج، موقع سيارة، السوق المفتوح، كارسويتش، وإكسبات (expatriates.com).
البيانات مأخوذة بتاريخ 27 أكتوبر 2026، وتشمل إعلانات آخر أسبوعين (وثلاثة أسابيع في إكسبات)، وبعضها ممكن يكون انباع.

افتح الصفحة من رابط GitHub Pages الموجود في وصف المستودع.
