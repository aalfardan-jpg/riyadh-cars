# بيك أب وعائلي في الرياض حتى 120 ألف ريال

صفحة فيها إعلانات بيك أب وسيارات عائلية في الرياض حتى 120 ألف ريال، من حراج وموقع سيارة والسوق المفتوح، بدون الماركات الصينية.
البيانات مأخوذة بتاريخ 18 أكتوبر 2026، وبعض الإعلانات ممكن تكون انباعت.
